# <img src="assets/icon-128.png" width="48" align="top" alt="Endless Dungeon icon"> Endless Dungeon

[English](README.md) | **繁體中文** | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Español](README.es.md)

一款行動裝置優先（橫屏）的單人 Roguelite：在有高低差的六角地圖上逐格探索、以骰子決定的武器戰鬥、招募同伴，並在多次探險之間成長。使用 Godot 4 與 GDScript 開發。

## 狀態

- 目前版本：v0.1.0-alpha，可遊玩的 3D 六角地圖 Roguelite，包含多層與 Boss 層、骰子戰鬥、狀態效果、裝備與背包、敵人移動、勸降與傭兵、跨層保留，以及本機存檔與續玩。金幣經濟尚未實作。
- 網頁試玩版：https://pluckyraven.eu.cc (備用/backup: https://endlessdungeon-284529.gitlab.io)
