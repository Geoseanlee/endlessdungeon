# <img src="assets/icon-128.png" width="48" align="top" alt="Endless Dungeon icon"> Endless Dungeon

[English](README.md) | [繁體中文](README.zh-TW.md) | **简体中文** | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Español](README.es.md)

一款移动端优先（横屏）的单人 Roguelite：在有高低差的六角地图上逐格探索、以骰子决定的武器战斗、招募同伴，并在多次探险之间成长。使用 Godot 4 与 GDScript 开发。

## 状态

- 当前版本：v0.1.0-alpha，可玩的 3D 六角地图 Roguelite，包含多层与 Boss 层、骰子战斗、状态效果、装备与背包、敌人移动、劝降与佣兵、跨层保留，以及本地存档与续玩。金币经济尚未实现。
- 网页试玩版：https://pluckyraven.eu.cc (backup: https://endlessdungeon-284529.gitlab.io)
