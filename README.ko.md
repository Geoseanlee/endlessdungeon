# <img src="assets/icon-128.png" width="48" align="top" alt="Endless Dungeon icon"> Endless Dungeon

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | **한국어** | [Deutsch](README.de.md) | [Español](README.es.md)

모바일 우선(가로 화면)의 싱글플레이어 로그라이트입니다. 높낮이가 있는 육각형 맵을 한 칸씩 탐험하고, 주사위로 결정되는 무기로 싸우며, 동료를 영입하고, 런(플레이) 사이에 성장할 수 있습니다. Godot 4와 GDScript로 개발했습니다.

## 상태

- 현재 버전: v0.1.0-alpha. 플레이 가능한 3D 육각형 로그라이트이며, 여러 층과 보스 층, 주사위 전투, 상태 이상, 장비와 가방, 적의 이동, 설득과 용병, 층 간 유지, 로컬 저장 및 이어하기를 지원합니다. 골드 경제는 아직 구현되지 않았습니다.
- 웹 체험판: https://pluckyraven.eu.cc (backup: https://endlessdungeon-284529.gitlab.io)

이 프로젝트는 **클로즈드 소스**입니다. 소스 코드, 에셋, 빌드 스크립트는 여기에 공개되어 있지 않습니다. 이 저장소에는 프로젝트의 커밋 기록(개발 타임라인과 기여자)과 이 README만 공개되어 있습니다.

작성자의 서면 허가 없이 이 프로젝트의 어떤 내용도 복제, 배포, 수정할 수 없습니다.
