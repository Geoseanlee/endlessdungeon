# <img src="assets/icon-128.png" width="48" align="top" alt="Endless Dungeon icon"> Endless Dungeon

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | **Español**

Un roguelite para un jugador, pensado primero para móvil (horizontal): explora un mapa hexagonal con desniveles casilla a casilla, lucha con armas basadas en dados, recluta compañeros y progresa entre partidas. Desarrollado con Godot 4 y GDScript.

## Estado

- Versión actual: v0.1.0-alpha, un roguelite hexagonal 3D jugable con varias plantas y plantas de jefe, combate con dados, efectos de estado, equipo y mochila, movimiento de enemigos, reclutamiento y mercenarios, continuidad entre plantas, y guardado y continuación locales. La economía de oro aún no está implementada.
- Versión web jugable: https://pluckyraven.eu.cc (backup: https://endlessdungeon-284529.gitlab.io)
