# <img src="assets/icon-128.png" width="48" align="top" alt="Endless Dungeon icon"> Endless Dungeon

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | **日本語** | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Español](README.es.md)

モバイル優先（横画面）のシングルプレイヤー・ローグライトです。高低差のある六角形マップを一マスずつ探索し、サイコロで決まる武器で戦い、仲間を勧誘し、ラン（周回）をまたいで成長していきます。Godot 4 と GDScript で開発しています。

## ステータス

- 現在のバージョン：v0.1.0-alpha。遊べる 3D 六角マップのローグライトで、複数フロアとボスフロア、サイコロ戦闘、状態異常、装備とバックパック、敵の移動、説得と傭兵、フロアをまたぐ引き継ぎ、ローカルのセーブと再開に対応しています。ゴールド経済はまだ実装されていません。
- ブラウザ版（試遊）：https://pluckyraven.eu.cc (backup: https://endlessdungeon-284529.gitlab.io)
